# Список команд
## LOAD
значения поля: 0
\nОписание: Загрузка константы по адресу
## WRITE
значения поля: 4
\nОписание: Запись значения из одного адреса в другой
## MUL
значение поля: 6
\nОписание: Умножение двух хначений и запись результата
## READ
значение поля: 8
\nОписание: Чтение константы из области программы
